# Reelcase mission plan

The in-app **Mission plan** tracks these larger, local-first improvements:

1. Durable media index — cached catalog metadata, source health, thumbnail hygiene, and fast search.
2. Desktop companion — explicit local-file verification, folder watching, and approved shortcut launching.
3. Watch room reliability — LAN discovery, clock correction, queue integrity, and guest checks.
4. Connected services — independently cached Twitch, YouTube, Roku, Spotify, and photo refreshes.
5. VR theater reliability — validate WebXR support before entry, render a real headset cinema surface, and report clear Meta Quest recovery steps when immersive playback is unavailable.

Each milestone is broken into an implementation change, a browser verification, and a production build check. The interactive checklist is saved in the browser under `reelcase.mission-plan.v1`.
